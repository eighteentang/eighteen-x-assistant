# X Assistant

在 x.com 上做减法的浏览器扩展 —— 把时间线里不想看的东西挡掉，把想看的东西标出来。

> **状态：规划中。** 目前只有想法，没有代码。
> 所有想法、排期与讨论都在 [Issues](../../issues)，**仓库里不放清单文件**。

## 第一版范围

| # | 功能 | 一句话 |
|---|---|---|
| 1 | 流速徽章 | 每条推文显示每小时浏览量，先做胶囊样式 |
| 2 | 内容过滤 | 屏蔽黄推、特定关键词、非指定语言的推文 |
| 3 | 流速过滤 | 低于指定流速阈值的推文直接隐藏 |
| 4 | 快速评论 | 预设 10 条常用评论，一键粘贴到回复框 |

原则：**先做简单能用的，再拓展。** 不追求一版做全。

## 技术前提

要拿到「每小时浏览量」，只能从 X 的 GraphQL 响应里取指标 —— 也就是说**必须 hook 页面的 `fetch` / `XMLHttpRequest`**，解析未公开的响应结构，并处理 X 的反滥用签名。

这不是可选项，砍功能也省不掉：只要涉及推文指标，就得走这条路。详见 Issues 里的「技术前提」。

兜底：hook 不到时回退到 DOM 解析，从 `article` 节点抽可见字段 —— 精度低，但徽章至少能显示。

## 技术形态

Chrome MV3 扩展（暂定）。参考项目同时提供油猴脚本版本，是否跟做待定。
